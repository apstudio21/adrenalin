# Адреналін — Драгобрат

Новий сайт готельно-ресторанного комплексу «Адреналін» (курорт Драгобрат).
Статичний сайт: HTML + CSS + JS, без збірки. Хостинг — Cloudflare Pages.

## Структура

```
index.html            головна сторінка (зимова версія)
css/styles.css        стилі
js/main.js            анімації, сніг, мапа, галерея, відгуки, бронювання
assets/img/           фото (WebP)
assets/fonts/         шрифти Cormorant Garamond + Manrope (OFL)
assets/logo/          логотип (SVG) + генератор make_logo.py
tools/                службові скрипти (завантаження оригінальних фото)
_headers              кешування для Cloudflare Pages
```

## Що вже зроблено

- Головна сторінка, зимова версія: стартовий екран із силуетом гір і рейтингами,
  цифри, «Про нас», номери з деталями, послуги, інтерактивна мапа Драгобрату,
  галерея, слайдер відгуків, бронювання у Viber / Telegram, футер.
- Сніг поверх сайту (можна вимкнути кнопкою в шапці).
- Перемикач «Зима / Літо» — літня версія в планах.

## Бронювання

Форма не відправляє дані на сервер. Вона збирає готове повідомлення
(номер, дати, гості, ім'я, телефон) і відкриває чат відділу бронювання:

- **Viber** — текст підставляється в поле повідомлення автоматично;
- **Telegram** — відкривається чат, текст копіюється в буфер обміну
  (Telegram не дозволяє підставити текст у чат за номером телефону).

Номер для заявок задається в `js/main.js` → `BOOKING_PHONE`.

## Плани

- Літня версія головної
- Інші сторінки (ресторан, як доїхати, документи)
- Адмінка Decap CMS для цін і акцій
- Оригінальні фото з сайту готелю (`python3 tools/fetch_originals.py`)

## Логотип

Шрифт — Montserrat Italic (OFL), літера «д» в рукописній формі, як на вивісці.
Лінія-хребет над словом — з неонової вивіски. Перегенерувати:
`python3 assets/logo/make_logo.py assets/logo`
